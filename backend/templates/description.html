Project overview · Machine learning

Smarter maintenance.
Fewer surprises.

SmartPM is a machine-learning-based predictive maintenance project designed to estimate whether an industrial machine may experience failure based on its operating measurements.

01 / Machine data to useful predictions
Core model

Random Forest
Classifier

The model evaluates selected machine features and returns a prediction for normal operation or potential failure.

ML + Analytics
01 — The purpose

Understand the machine before a problem grows.

Unexpected machine downtime can interrupt production and increase maintenance costs. SmartPM demonstrates how historical machine data and a trained classifier can support earlier risk identification.

⌁

The challenge

Reactive maintenance can identify a problem only after symptoms appear or equipment stops working.

◈

The approach

Use air temperature, process temperature, rotational speed, torque, tool wear, and machine type as model inputs.

↗

The outcome

Present a machine status prediction and model evaluation metrics in one accessible dashboard.

02 — How it works

From measurements to a prediction.

The application connects a trained ML model to a web interface so users can enter machine values and view the result.

STEP 01

Input data

Enter the machine type and operating measurements.

STEP 02

Validate

Check that entered values are valid and within allowed ranges.

STEP 03

Predict

Pass the selected features to the trained Random Forest model.

STEP 04

Review

Display the predicted status and review model performance.
